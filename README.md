# 塔防设计师

一个用中文和你一起设计塔防游戏的 Codex Skill。带来一座塔、一张卡住的地图，或者一句“我想做个不一样的塔防”就能开始。它会把建议落到某一波怪、某个塔位，以及下一次试玩能观察到的变化。

## 试着这样聊

> 打开塔防设计师。我做了一座贯穿激光塔，但玩家每次都摆在同一个拐角。怎么让另一个位置也值得考虑？

一种可以马上做的灰盒测试是给地图加一条侧路。直道能让一发激光穿过整排怪，靠出口的塔位则能同时照顾两路。第一波只出长队，第二波让侧路的两只快怪提前进场。保留两个位置的造价和塔伤，看看玩家第二次会不会主动换塔位。这样一次试玩就能看出，是位置之间有了取舍，还是原来的拐角依然样样都赢。

## 它可以陪你做什么

- **找玩法方向。** 把卡牌留解、经营停产或战前换位这样的决定，改写成玩家在防线上要承担的一次风险。
- **推演塔、敌人和经济。** 用同一波怪比较两个塔位，把射界、攻击间隔、过量伤害和漏怪一起算进去。
- **安排下一次试玩。** 给一个值得验证的问题、一处小改动，以及能让你改变判断的现象。
- **把机制落进 UE5 蓝图。** 例如从激光塔的碰撞盒开始，接到可搜索的节点，再用盒内两只怪、盒外一只怪验收。

## 安装

下载仓库 ZIP 并解压，在个人技能目录下新建 `tower-defense-creative-director` 文件夹，将仓库中的 [SKILL.md](SKILL.md) 放进该文件夹。最终路径如下。

- Windows：`%USERPROFILE%\.agents\skills\tower-defense-creative-director\SKILL.md`
- macOS / Linux：`~/.agents/skills/tower-defense-creative-director/SKILL.md`

打开新的 Codex 对话，输入 **打开塔防设计师**。已经在讨论塔防时，也可以说 **打开设计师功能**。技能正文是一个 Markdown 文件，讨论玩法时无需安装 UE5。
